# God's Eye View — обзор формата, источников и отрисовки

Краткий технический отчёт по репозиторию: что это за приложение, откуда берёт данные и как рисует 3D-сцену, включая проекцию публичных камер.

---

## 1. Что это за продукт

**God's Eye View** — локальный **OSINT / GEOINT-клиент** в браузере: фотореалистичный 3D-глобус с живыми слоями (самолёты, корабли, спутники, камеры, пожары, трафик) и голосовым управлением.

Это **не облачный SaaS** и не настольное приложение. Формат такой:

| Слой | Что это |
|------|---------|
| Тип | SPA (single-page app) + локальный Node/Vite-сервер |
| Язык | **Vanilla JavaScript (ES-модули)**, без React/Vue. Шейдеры — **GLSL**. Сборка — **Vite 6** |
| 3D-движок | **CesiumJS** (~1.124) |
| Запуск | `npm run dev` → `http://localhost:4173`, либо установщик [Pinokio](https://pinokio.co/) |
| Лицензия кода | MIT. Данные третьих сторон — свои лицензии (`DATA_SOURCES.md`) |

Браузер рисует сцену. Локальный сервер (middlewares в `vite.config.js`) проксирует внешние API: обходит CORS, прячет ключи, кэширует ответы и режет SSRF. В браузер уходят только ключи карт (Google Maps / Cesium ion).

Итог: **локальный веб-сервис на своей машине**, не публичный бэкенд. Хостинг обещают отдельно; этот репозиторий — открытый клиент.

## 2. Как устроена картинка

Конвейер снизу вверх:

1. **Базовая карта (basemap)** — Cesium `Viewer` в `#cesiumContainer`.
2. **Живые слои** — billboard'ы, 3D-модели, полилинии, примитивы.
3. **Аннотации** — контуры, маршруты, подписи, «приклеенные» к 3D-тайлам.
4. **Постпроцесс** — GLSL-фильтры (CRT, NVG, FLIR и т.д.).
5. **Screen-space оверлеи** — detection-бокс, карточки CCTV, круглая «труба» (scope mask).

### Базовые карты

Лестница в `mapStackController.js`:

| Есть ключи | Что видите |
|------------|------------|
| Ничего | Esri World Imagery (спутник, 2D) + keyless-рельеф Re:Earth / Mapterhorn. Если Esri недоступен — OSM |
| Cesium ion | **Google Photorealistic 3D Tiles** (меш городов) + world terrain |
| Google Maps key | Те же 3D-тайлы напрямую + поиск мест |

3D-города — это **потоковые photogrammetry-тайлы**, не своя модель зданий. Без ion/Google глобус плоский (спутниковая текстура + рельеф).

Дополнительно: Bing Aerial / Bing Labels (через ion).

### Как живут объекты на глобусе

- **Самолёт / корабль** — GPU-батч `BillboardCollection`. Курс проецируется в screen-space (`iconOrientation.js`), чтобы иконка смотрела по реальному heading при любом угле камеры.
- **Трекинг** — фиды приходят раз в 15–30 с. Сцена идёт на один интервал позади реального времени и интерполирует между фиксами; дыры заполняет dead reckoning. Новый фикс въезжает lerp'ом (~1 с), без скачка.
- **Высота** — геоид (EGM96 / EGM2008) + сэмпл **уже отрисованного** меша (`groundFloor.js`, `meshFloorSampler.js`, `/api/terrain/heights`). Самолёт садится на перрон, камера стоит на тротуаре, а не «висит» над эллипсоидом.
- **Спутники** — TLE с CelesTrak, распространение **SGP4** (`satellite.js`). Кольца орбит держатся через GMST, без дрейфа.
- **Аннотации зданий** — не бокс по пикселям кадра. Имя места → геокод + контур OSM (Overpass). Для здания Cesium **Classification** красит сам photogrammetry-меш внутри вертикальной колонки (`classificationType: CESIUM_3D_TILE`). Район — плоский полигон, натянутый на тайлы.

Detection overlay (`D`) — **не нейросеть**. Это экранные угловые скобки и ID поверх уже известных объектов слоя (самолёт, корабль, спутник) на 2D-canvas.

## 3. Источники данных и как они подключаются

Каждый слой — отдельный модуль в `src/data/`. Менеджер (`manager.js`) включает/выключает их единообразно.

### Живые фиды (запрос в рантайме)

| Слой | Источник | Как используется |
|------|----------|------------------|
| Самолёты | **OpenSky** (основной), **adsb.lol** (fallback / военные) | Снимок state vectors через `/api/opensky`. Военные ICAO — отдельный реестр adsb.lol |
| Корабли | **AISStream** | WebSocket через сервер, ключ не светится в браузере |
| Спутники | **CelesTrak** TLE | Каталог ~838 объектов + опционально плотная оболочка Starlink |
| Землетрясения | **USGS** | События за 24 ч |
| Пожары | **NASA FIRMS** (VIIRS NOAA-20/21 + Suomi-NPP) | Прокси `/api/firms`, хвост 24 ч, кэш ~30 мин |
| Трафик | **OSM Overpass** (геометрия дорог) + опционально **TomTom** flow tiles | Машины **симулируются** по дорогам. TomTom красит скорость/пробки, не даёт живые позиции авто |
| CCTV | Austin Open Data, **Caltrans**, **TfL JamCams** | Каталог + кадры через `/api/cctv/*`. Позы — оценки, не заводская калибровка |
| Радио | **Radio Browser** | Справочник станций; поток идёт **напрямую** от вещателя |
| Велопрокат | **GBFS** | Живая занятость станций |
| Пуски | **Launch Library 2** | Метаданные за 30 дней; траектория — реконструкция, не телеметрия |
| Погода в кабине | **Open-Meteo** | Наблюдения → объёмные облака (WX) |
| Новости в кабине | Google News RSS, fallback **GDELT** | Подбор по locality, не «инциденты» |
| Военные объекты | OSM Overpass (`military=*`) | Только viewport, неполная карта контекста |

### Статика в репозитории (`src/data/local_data/`)

- Датацентры (~4 351) — выгрузка OSM, ODbL
- Плотины (704) — OpenInfraMap / OSM, ODbL
- Подводные кабели (712) — TeleGeography, **CC BY-NC-SA** (не для коммерции без лицензии)
- Регионы Natural Earth — офлайн-контуры для голоса («обведи Альпы»)
- Районы Сан-Франциско — DataSF, для «outline Chinatown»

### Голос и поиск

- **OpenAI Realtime API** — 28 инструментов (камера, слои, аннотации, аналитика). Ключ только на сервере; браузер получает короткий session token.
- Геокодинг / контуры: Google Places (если есть ключ), иначе Nominatim + Overpass.
- Маршруты: внешний роутер; если его нет — прямая линия с явной подписью, без «фейковой дороги».

## 4. Фильтры и постпроцесс

Это **не** ГИС-фильтры данных. Это **сенсорные луки** поверх уже собранного кадра Cesium.

Клавиши `1`–`7`. Каждый стиль — `Cesium.PostProcessStage` с fragment shader из `src/styles/`. Неактивные стадии выключены (`enabled = false`), чтобы не жечь GPU. Переключение — кроссфейд по `intensity`.

| Клавиша / имя | Шейдер | Что делает |
|---------------|--------|------------|
| NORMAL | — | Сырой глобус |
| CRT (`retro`) | `retro.js` | Пикселизация, Bayer dither, бочка, scanlines, хроматика, виньетка, phosphor ghost, jitter |
| NVG (`surveillance`) | `surveillance.js` | Зелёный P43, bloom трубки, honeycomb, scintillation, barrel, автогейн |
| FLIR (`thermal`) | `thermal.js` | «Температура» из яркости кадра: White-Hot / Black-Hot, Ironbow, banding, IR bloom. **Не настоящий ИК** |
| ANIME | `anime.js` | Цел-шейдинг, насыщенность, обводка |
| NOIR | `noir.js` | Десатурация, S-кривая контраста, зерно, виньетка |
| SNOW | `snow.js` | Обесцвечивание + падающие частицы |

Дополнительно, не стили:

- **Sharpen** — unsharp mask (по умолчанию ~49%).
- **Bloom** — штатный bloom Cesium, по умолчанию выключен.
- **Scope mask** (`scopeMask.js`) — круглая «труба» на 2D-canvas, не шейдер. Края чернеют быстрее при снижении высоты.
- В кабине стили те же; WX добавляет объёмные облака из Open-Meteo.

Detection подстраивает цвета под CRT / NVG / FLIR (`DETECTION_THEME_MAP`).

## 5. Камеры: проекция кадра и «видимость» на зданиях

Важный факт: кадр **не натягивается на фасады** как проектор (нет homography / projective texture mapping по стенам). Схема — **усечённая пирамида (frustum) + «монитор» на дальнем торце**.

### Откуда берутся камеры

Каталог = сиды (`CAMERA_SEEDS` в `cctv.js`) + живые источники `/api/cctv/sources`.

Позиция (lat/lon) — из открытых каталогов городов. Ориентация — **оценка**:

1. Числовой heading / bearing в записи.
2. Поле направления: `travel_direction`, `facing`, Caltrans `location.direction` → `directionToHeading()` (`NORTHBOUND` → 0°, `SB` → 180°). В свободном названии («WEST AVE») голое «West» **не** считается курсом.
3. Если ничего нет — детерминированный hash ID → один из 16 курсов (шаг 22.5°).
4. Pitch по умолчанию около **−17°** (смотрит вниз). FOV ~70–74°, дальность ~700 м, высота столба ~22–24 м.

В README это названо честно: *poses are estimated priors*. Довести можно **гизмо на самой камере** (heading, pitch, FOV, range, сдвиг N/E, высота). Калибровка пишется в `localStorage` (`godsEyeView.cctv.calibration.v2`).

Высота столба: батч эллипсоидальных высот Re:Earth, затем один сэмпл меша Google 3D (когда тайлы догрузились). Для режима «плоский глобус» — DEM/prior.

### Геометрия frustum (`computeFrustumGeometry`)

Чистая поза, без запросов к сцене:

```
mountAlt  = ground + mountHeight
capCenter = точка на дальности R по heading/pitch
halfW     = R · tan(hFov / 2)
vFov      = 2 · atan(tan(hFov / 2) / (16/9))
```

Четыре луча от столба к углам дальней плоскости 16:9 + замкнутый прямоугольник. Центр дальнего торца не опускается ниже `ground + 2 м`, чтобы «монитор» не уехал под землю.

### Куда кладётся картинка

При активации камеры:

1. **Один** `scene.pickFromRay` вдоль оси frustum — единственный raycast подсистемы.
2. Если луч бьёт в 3D-тайл (здание, земля), дальность **укорачивается** до `hit − 4 м`, но не короче 12 м.
3. На этом торце ставится **плоскость-монитор**, нормаль назад к столбу. Текстура 16:9, не billboard: плоскость не крутится за зрителем.

Кадр:

- видео — `HTMLVideoElement` как текстура Cesium;
- фото — два offscreen canvas, смена ≤1 Гц (Cesium перезаливает текстуру только при новом объекте).

Активная камера — один монитор. Остальные: иконка + опциональная экранная карточка превью.

Режимы покрытия:

| Режим | Что рисуется |
|-------|----------------|
| OFF | Только иконки |
| ON | Каркас пирамиды |
| VIEWSHED | Полупрозрачный объём (5 вершин, 6 треугольников), цвет по golden-angle hue |

**Viewshed здесь — декоративный конус**, не аналитическая видимость (нет shadow map / voxel LOS). «Слепые зоны» — там, где конус обрезан лучом или ушёл за меш.

### Чего система не делает

- Не восстанавливает точную extrinsics/intrinsics камеры.
- Не проецирует пиксели на стены (нет projective mapping).
- Не считает истинный viewshed по зданиям.
- Не ищет людей и не делает face recognition — продуктовое ограничение репозитория.

## 6. Коротко: как смотреть на это как на OSINT-инструмент

Сильная сторона — **сведение открытых сигналов на одном глобусе** и быстрый переход «самолёт → кабина → ближайшая камера».

Слабая — **оценки вместо измерений**: позы CCTV, симулированный трафик, реконструкция пусков, неполный OSM по военным объектам. Приложение само это маркирует (`RAW PRIOR`, `RECONSTRUCTED ESTIMATE`, attribution lightbox).

Для расширения слой — это паттерн: модуль с `init / enable / disable / update` + прокси в Vite + кредит в `dataCredits.js`.
